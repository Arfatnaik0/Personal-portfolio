# Personal Portfolio - Arfat Naik

A modern, responsive personal portfolio website showcasing my projects, skills, and professional experience.

## 🌟 Features

- **Responsive Design**: Fully responsive layout that works seamlessly across all devices
- **Interactive UI**: Custom cursor effects and smooth animations
- **Project Showcase**: Display of featured projects with descriptions and links
- **Skills Section**: Visual representation of technical skills and expertise
- **Contact Form**: Easy way for visitors to get in touch
- **Downloadable Resume**: Direct access to resume and certifications

## 🛠️ Technologies Used

- **HTML5**: Semantic markup structure
- **CSS3**: Custom styling with modern features
- **JavaScript**: Interactive elements and functionality
- **Google Fonts**: Typography enhancement

## 📂 Project Structure

```
Personal-portfolio/
├── index.html          # Main HTML file
├── style.css           # Stylesheet
├── script.js           # JavaScript functionality
├── images/             # Image assets (profile, projects, icons)
├── skills/             # Resume and certifications
│   ├── Arfat Resume.pdf
│   └── certifications.pdf
└── README.md           # Project documentation
```

## 📱 Sections

- **Home**: Introduction and brief overview
- **About**: Personal information and background
- **Skills**: Technical skills and proficiencies
- **Projects**: Portfolio of completed projects
- **Contact**: Contact form and social media links
